Note 01

まずはこれだけ——「任せ方」3つのコツ

Gensparkは無料アカウントで使い始められます。まずは有料を考えず、無料の範囲で「任せ心地」を確かめるのがおすすめです。

最初につまずくのは「何をどう頼めばいいか分からない」という壁。といっても、コツは3つだけです。

  • ① 目的と相手を言う——「何のために・誰が読むか」を添える。同じ“まとめて”でも、自分用のメモと上司への報告では中身が変わります。
  • ② 出力の形式を指定する——「箇条書きで」「表で」「スライドで」。形式を伝えるだけで、手直しが一気に減ります。
  • ③ 量も伝える——「3案」「10枚以内」「1ページに」。多すぎる返事は、量を指定するだけで治ります。
ちょっとした例：「営業資料を作って」ではなく
「中小企業の経営者向けに、うちのサービスの紹介資料をスライド8枚で作って。強みは納品の速さです」

いきなり完璧な依頼文を目指さなくて大丈夫。まず「おまかせ」で投げて、返ってきたものを見ながら「ここをもっとこうして」と詰めていく——それがエージェント型の付き合い方です。

Note 02

資料づくりがいちばん体感しやすい——リサーチからスライドまで

Gensparkを使い始めた人がいちばん「これは楽になった」と言いやすいのが資料づくりです。週報やセミナー資料を例に、流れを追います。

  • ステップ1：調べてもらう——まず必要な情報を集めさせます。「◯◯業界の今年の動向を、出典つきで調べて」。この“出典つき”がポイントです。
  • ステップ2：スライドにしてもらう——AIスライドにそのまま渡します。「これを10枚のスライドにして、1枚ごとに言いたいことを大見出しで」。
  • ステップ3：手直しを頼む——「3枚目を数字ベースに」「最後にまとめの1枚を追加」。最初から作り直すのではなく、上書きで詰めます。
  • ステップ4：書き出す——PowerPoint形式などで出力して、あとは自分の仕上げ。見た目の微調整だけ人間がやるのが効率的です。

この流れを一度やってしまうと、「白紙のスライドとにらめっこ」には戻れなくなります。内容の判断は自分が行い、形にする作業を任せる——分担が決まるのが一番の収穫です。

Note 03

調べものは「ディープリサーチ」に任せる——出典つきレポートの使いどころ

Gensparkのディープリサーチは、複数の情報源を渡り歩いて1冊のレポートにまとめてくれます。ただし、なんでもかんでも使えばいいわけではありません。

使うと良い場面は、比較検討・調べたかったのに終わらない類のもの。「導入するか迷っているツールの比較」「業界の基礎知識のキャッチアップ」「誌面に載せる市場概況」など、情報が散らばっていて、まとめる手間が本体みたいな調べものです。

逆に使わなくていい場面は、答えが1行で十分なとき。営業時間や住所の確認に数分待つのは、道具を取り違えているだけです。そのへんは通常のチャットで十分です。

最後にひとつだけ習慣を。レポートを受け取ったら出典を必ず1〜2件、自分の目で開くこと。AIのまとめは便利ですが、最終確認だけは手を動かす人間の仕事です。ここを守ると、任せられる範囲がぐっと広がります。

Note 04

議事録づくりを任せる——走り書きメモが「使える記録」になるまで

会議の記録づくりは、地味に時間を取られる仕事です。ここは任せる効果がいちばん分かりやすいところ。しかも、会議中にきれいに書く必要はありません。走り書きのメモをそのまま渡すのがコツです。

  • 渡すもの——会議中に取った殴り書きのメモ。箇条書きでも、言い間違いや書きかけが混ざっていても大丈夫です。議題のタイトルと日付だけ添えておくと精度が上がります。
  • 誰が読むかを言う——「参加できなかった人に共有する」「上司に報告する」。同じメモでも、共有用は経緯厚め、報告用は結論と数字が前に出ます。
  • 分け方を指定する——「決定事項・やること・保留の3つに分けて」と伝えるだけで、あとから読み返せる形になります。担当と期限があれば、それも拾わせます。
  • 最後に自分で確認する——人名・金額・日付は、書き間違いが混ざりやすいところです。受け取ったあと、そこだけ自分の目で照合します。
ちょっとした例：「以下の会議メモを、決定事項・やること・保留の3つに分けた議事録にして。読むのは参加できなかったメンバーなので、結論を先に、経緯は短く。やることには担当と期限を入れて」
（続けて、そのまま殴り書きのメモを貼り付ける）

ポイントは、メモを「きれいに整える」作業と、「誰に何を伝えるか決める」作業を切り分けること。前者は任せて、後者は自分が握る。この分担に慣れると、会議が終わった時点で記録がほぼ完成している状態になります。

Note 05

画像づくりを任せる——言葉だけで、SNS用の1枚を作る

「画像は自分で作れないから」と諦めていた人にこそ試してほしいのが画像づくりです。写真素材を探す代わりに、作りたい絵を言葉で説明するだけで1枚が出てきます。絵心も、ソフトの操作も要りません。

  • 使い道を言う——「Xのプロフィール用」「ブログ記事の見出し画像」。用途が伝わると、構図や余白の取り方が変わります。
  • 雰囲気を言葉にする——色（例：落ち着いた緑）、明るさ、画風（写真風／イラスト風／手描き風）。ここを最初に伝えると、方向性がぶれません。
  • 文字を入れるなら、文言をそのまま指定する——「この文字を入れて」と正確に伝えるのが大事です。長い文章は崩れやすいので、入れるなら短い言葉（数文字〜ひと言）に絞ると安定します。
  • 一気に決めない——返ってきた絵に対して「もっと明るく」「人物を小さく」「背景を白っぽく」。一度に1点ずつ変えると、狙った方向へ確実に寄っていきます。
ちょっとした例：「ブログの見出し用に、落ち着いた緑と生成り色で、机の上でノートと鉛筆が並んでいる静かな写真風の画像を作って。横長で、文字は入れないで」
（→ 返ってきたものを見て「もうちょっと明るく」「ノートを大きく」と1点ずつ調整）

コツは、「完成形を最初から言い当てる」のではなく、「1点ずつ直して寄せていく」こと。ここは資料づくりと違って、何回か往復するのが普通です。3回やり取りすれば、たいてい使える1枚になります。

Note 06

うまくいかないときの直し方——つまずきは3パターンだけ

使い始めの人が「向いてないのかも」と感じる原因は、たいていこの3つです。どれも言い直し方を知っているだけで解決します。順番にいきましょう。

  • ① 抽象的なまま投げてしまう——「いい感じにまとめて」だけだと、平均的な返事しか来ません。例を1つ添えるのが特効薬です。「前に送ったあのメールの文体で」「この構成をまねて」。実物を1つ見せるだけで、一気に近づきます。
  • ② 一度に全部を詰め込む——調べる・構成する・書く・画像を作るを、1回の依頼に入れてしまうパターン。これは分けて頼むほうが速くて正確です。前の工程の結果を渡して、次の工程を頼む。バトンのように繋ぎます。
  • ③ 返ってきたものを、丸ごと作り直そうとする——「全部やり直して」では、良かった部分まで消えてしまいます。差分で頼むのがコツ。「2番目の案はそのままで、1番目だけ数字を入れて」「3枚目の見出しだけ短く」。上書き方式です。

そして、ここが一番大事なところです。期待と違う返事が来るのは、失敗ではありません。会話が1回増えただけです。むしろ、どこが違うかを言葉にする作業そのものが、自分の中で「本当に欲しいもの」をはっきりさせていきます。

白紙から自分で作る場合、その「本当に欲しいもの」を考える時間も自分で負担します。任せれば、たたき台が出てくるぶん、考える手がかりが先に手に入る。これがエージェント型の付き合い方の、いちばんおいしいところです。
